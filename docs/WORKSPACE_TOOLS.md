# Camera presets and reference guides

The VRoid 2.14 adapter provides Cameras and Guides tabs in the English workspace panel. Tab toggles visibility by default; Workspace.ToggleKey changes the shortcut. Drag the title to move it, use Fold/Open to collapse it, and Reset to restore position/scale. Settings persist in configuration, but restart and alternative-scale acceptance remain pending. View tools do not write model content or enter undo history.

Camera controls support editing and photo booth, front/back/left/right body/head views, projection switching, size adjustment and session-view restoration. Ten slots per projection are shown in pages of five. Save/Recall/Clear act on the current bank. Position, target, rotation including roll, projection and size persist in `BepInEx/config/VRoidXYToolWorkspace.json`. Old four-slot files migrate by projection. Import legacy camera JSON converts both old banks from the absolute path copied to the clipboard.

Guides support multiple PNG/JPG images through the native picker or pasted paths. Screen references use normalized viewport X/Y and Z rotation; world references use the preserved original plane asset and all rotation axes. Each has visibility, scale, opacity and position controls. Screen grid and world ruler toggle independently. Save references writes `references.json` beside the camera presets and copies its path for exporting the file. Load references restores it; Import legacy JSON uses the picker. Missing files retain settings for retry. Hiding the panel leaves guides visible; clearing references, changing documents or unloading releases guide objects and textures.

Limits are 16 references, 4096 pixels per side, 64 MiB per compressed file and 256 MiB of accounted RGBA reference textures. Display-only textures discard their CPU pixels. Preset replacement also budgets incoming images while old references exist; clear old references first if the replacement reaches the budget. Unity destruction is deferred, so this is not an exact process-memory ceiling. Screen guides are clipped and do not intercept clicks. The picker currently shows all files and validates extensions before loading because its pinned extension-filter bindings are incompatible. Legacy source, assets and attribution remain preserved.

See [native acceptance](WORKSPACE_NATIVE_ACCEPTANCE.md) and [the completion checklist](LOCAL_COMPLETION_CHECKLIST.md) for passed and pending checks. Use the disposable application/model copies described in [installation](IL2CPP_INSTALLATION.md).
